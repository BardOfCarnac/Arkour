# Black ICE Glyph Editor

Standalone five-point 3D glyph editor for experimenting with Black ICE silhouettes without changing the Runner rig or runtime.

## Model

The five editable handles are arm tips. The filled contour is generated by inserting an automatic inward valley between each neighbouring pair, pulled toward the current five-point centroid by the `core` value. This keeps the authoring rig at exactly five points while still producing a starfish-like outline.

Seed asset: `starfish-v1.json`.

## Controls

- Front: X/Y drag plane
- Side: Z/Y drag plane
- Top: X/Z drag plane
- Orbit: camera-facing drag plane
- Selected Depth: precise Z editing for mobile
- Core / Arm Width: controls the inward valleys and therefore arm thickness
- Curve: contour smoothing
- Fill: preview opacity
- Flatten Z, reset, copy JSON, download JSON

The page is mobile-first: the canvas stays visible and the tool panel opens as a bottom sheet on phones or a right drawer on larger screens.
