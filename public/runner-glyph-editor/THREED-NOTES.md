# 3D model notes

The 3D editor treats the Runner as a warped sheet rather than an extruded solid. The accepted 2D outline remains the front-plane silhouette, while each semantic control point gains an editable Z coordinate.

This is intentional: Arkour's Runner should remain a glyph first and a body second. The current editor is for discovering a useful 3D pose vocabulary, not for committing to final production mesh topology.
